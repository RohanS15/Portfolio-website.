# Playground Tutorial Content

Reviewed 2026-11-11 against the implementation inventory. Tutorial content is authored in `src/tutorials/playgroundTutorials.ts`; every route uses the same flashcard UI and tool-specific content. All five tutorials open closed and require the matching **How to use** button.

## Code playground

1. Explains HTML, CSS, JavaScript, preview isolation, and the sandbox limitation.
2. Explains choosing Signal card or Status panel and the editor tabs; warns that changing examples replaces the draft.
3. Gives the edit → Run → preview loop and a concrete heading example.
4. Explains preview behavior, Copy, Fullscreen, Reset, and the sandbox's network/form restrictions.

## Portfolio terminal

1. Establishes that this is a simulated, read-only virtual filesystem, not the visitor's shell.
2. Explains quick commands, typed input, Enter, output, `help`, and `tree`.
3. Explains `cd`, `ls`, and `cat` against the published site data, with an example sequence.
4. Explains Tab completion, Up/Down command recall, `history`, `clear`, and session scope.

## Browser arcade

1. Introduces the challenge types, local score state, and timed-round caution.
2. Explains game selection, difficulty, and starting a run.
3. Explains submitting answers, feedback, explanations, and the distinction between game score and skill.
4. Explains round review, restarting, and local reaction-best persistence.

## Synthetic cyber lab

1. Identifies all five tabs and makes the synthetic/local scope clear.
2. Walks through selecting a Live Desk signal, reading evidence, choosing a response, and reviewing rationale.
3. Explains Signal Sprint and SOC Overview.
4. Explains the illustrative Playbook sample and educational ATT&CK Map.
5. Reinforces evidence-based conclusions and the lack of real-system actions.

## Workflow simulator

1. Explains node types, connectors, sample data, and local-only behavior.
2. Explains opening templates versus custom mode and selecting the inspector.
3. Explains output-to-input connections, decision Yes/No ports, and node positioning.
4. Explains configuring text matching and running/stopping a simulation.
5. Explains reading the execution log and the simulated nature of review/notification steps.
